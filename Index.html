⚡ Integração SIGE / Professor Online
💻 Computador / Notebook

Arraste o botão azul para a sua barra de favoritos no topo do navegador (Chrome, Edge, Firefox, etc.).

👇 Clique e arraste para os favoritos:
⭐ ProfOnline

Dica: use Ctrl + Shift + B se a barra estiver oculta.

Como funciona:
  1. Copie as notas na aba Resultados clicando em "📋 Copiar Notas".
  2. Abra o Professor Online na tela de digitação de notas.
  3. Clique no seu favorito ProfOnline salvo na barra!
Alternativa manual:
📱 Celular / Smartphone

No celular não é possível arrastar. Toque no botão para copiar o código e cole no campo URL de um favorito novo no seu navegador.

Clique para copiar o código do favorito

Passo a passo no Celular (Chrome):
  1. Toque em "📋 ProfOnline" acima para copiar o código.
  2. Favorite qualquer página tocando no menu (⋮) e na estrela (⭐).
  3. Toque em Editar, renomeie para ProfOnline e no campo URL cole o código copiado.
  4. No Professor Online (tela de notas), digite ProfOnline na barra de endereços e toque no favorito!
Compatibilidade: Chrome Android, Safari iOS, Edge
